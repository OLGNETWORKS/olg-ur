# Flujo Git obligatorio

- Antes de cualquier operación masiva —incluidos renombrados, borrados o llenado de contenido— crea un commit de respaldo con un mensaje descriptivo.
- Al terminar cada sesión que produzca cambios, revisa el diff, crea un commit descriptivo y ejecuta `git push` sin esperar a que el usuario lo solicite.
- Si el commit o el push requieren autenticación o una decisión sobre conflictos, detente y solicita intervención del usuario; nunca generes ni introduzcas credenciales por él.
